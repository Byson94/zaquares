# Calculate WPI

Zaquares paper explores the creation of a new WPI definition, WPI estimation with limited parameters using an AL/ML model, 
and full WPI trajectory and rate of change calculations. We provide a convenient abstraction over these with an easy to use
web interface:

- [Calculate WPI from full parameters](/calculate/wpi)
- [Estimate WPI from limited parameters (ML Model)](/calculate/estimate)
- [Calculate WPI trajectory](/calculate/#)

For more information on each WPI calculation, see [documents](/docs).
